# samples —— 真实拍照样张

放顾客真实发来的拍照文档，用来校准去底增强的参数、做回归测试的基准。

**去底算法的效果只能靠真实照片验证。**合成图能证明代码跑通，不能证明效果好不好。缺样张是当前 v1 最大的风险。

## 需要什么样的样张

3–5 张，尽量覆盖不同情况：

- 一侧有明显阴影（手机或人挡光）的
- 纸张发黄、有折痕的
- 有印章、手写签名的
- 拍歪了、带桌面背景的
- 表格类、多栏排版的

## 隐私

真实样张常含身份证、合同、成绩单。`.gitignore` 默认忽略本目录的所有文件，只有脱敏后确实可公开的才用 `git add -f` 单独提交。

## 命名

`<特征>-<序号>.jpg`，比如 `阴影-01.jpg`、`发黄折痕-01.jpg`、`带印章-01.jpg`。

调参结果记进 `docs/03-图片增强算法.md` 的调参记录表。
